# بطاقة دليل

مادة تدريبية اصطناعية: العيادة والأشخاص والأرقام من صنع المقرر، ولا تصلح مرجعًا سريريًا.

| البند | ما تكتبه |
|---|---|
| السؤال | المرضى، والتدخل، والمقارنة، والنتيجة |
| جواب المساعد | الادعاءات واحدًا واحدًا، كما قالها |
| لكل ادعاء: المصدر | هل هو موجود؟ افتحه. اكتب رقمه في PubMed |
| لكل ادعاء: الحكم | يطابق المصدر / يخالف المصدر / المصدر غير موجود / صحيح في مصدره ولا ينطبق على السؤال / المصدر قديم / ناقص: مصدر مخالف لم يُذكر |
| لكل ادعاء: ما وجدته | الرقم والنتيجة التي يخصها، بكلماتك |
| الحداثة | سنة النشر، وتاريخ آخر بحث إن كان المصدر مراجعة |
| الانطباق | من دُرس؟ وهل يشبه مريض السؤال؟ |
| الخلاف | هل يوجد مصدر يقول غير ذلك؟ |
| الجواب الذي يسنده الدليل | جملة أو جملتان |
| درجة اليقين | عالٍ / متوسط / منخفض، مع السبب في جملة |
| ما لم أتحقق منه | ما بقي مفتوحًا |

## مثال محلول: الادعاء الأول من السؤال الأول

| البند | المثال |
|---|---|
| الادعاء | «شملت التجربة 7,020 مريضًا، ومدة المتابعة الوسيطة 3.1 سنة.» |
| المصدر | موجود: https://pubmed.ncbi.nlm.nih.gov/26378978/ |
| الحكم | يطابق المصدر |
| ما وجدته | 7,020 مريضًا عولجوا، ومدة الملاحظة الوسيطة 3.1 سنة |
